# การเชื่อมต่อ FTP ของ RoietKPS

ค่าที่ผู้ใช้ยืนยันเมื่อวันที่ 9 พฤศจิกายน 2569:

- FTP Host: `ftp.roietkps.com`
- FTP Port: `2002`

ตรวจการเชื่อมต่อโดยไม่เข้าสู่ระบบแล้ว เซิร์ฟเวอร์ตอบรับ FTP และรองรับ explicit TLS ที่โฮสต์/พอร์ตนี้

ใช้ค่าข้างต้นเมื่อเชื่อมต่อผ่าน FileZilla หรือวินิจฉัยปัญหา FTP ของโฮสต์นี้ พอร์ตมาตรฐาน `21` ไม่ใช่พอร์ต FTP ที่ถูกต้องสำหรับบริการนี้ ส่วนพอร์ต `2222` เป็นพอร์ตแผงควบคุม DirectAdmin

ไม่ได้บันทึกรหัสผ่านไว้ในไฟล์นี้

## ใช้งานผ่าน VS Code

ตั้งค่าใน `.vscode/sftp.json` สำหรับส่วนขยาย **SFTP — Natizyskunk** ไว้แล้ว:

- Protocol: `ftp` พร้อม `secure: true` (FTP ผ่าน TLS)
- Username: `test@roietkps.com` ตามบัญชีในภาพที่ผู้ใช้ให้ไว้
- Remote path: `/` ซึ่งเป็นโฟลเดอร์รากที่บัญชี FTP นี้มองเห็น ต้องตรวจรายการไฟล์หลังเข้าสู่ระบบก่อนอัปโหลด
- ไม่อัปโหลดเมื่อบันทึกไฟล์ และไม่ลบไฟล์ปลายทางระหว่าง sync
- ไม่ใส่รหัสผ่านในไฟล์ ให้กรอกผ่านช่องรับรหัสผ่านของส่วนขยาย
- ยกเว้นไฟล์ Git, การตั้งค่า VS Code, ไฟล์สร้างวิดีโอ/ทดสอบ และ `config/db.php` ของเครื่องพัฒนา
- `.vscode/sftp.json` ถูกยกเว้นจาก Git

วิธีเริ่มใช้งาน:

1. หลังปิดส่วนขยาย Easy SFTP ที่ซ้ำกันเฉพาะ Workspace ให้รัน **Developer: Reload Window** หนึ่งครั้ง
2. กด `Cmd+Shift+P` แล้วเลือก **SFTP: List** จากนั้นกรอกรหัสผ่านบัญชี FTP ใน VS Code
3. ตรวจว่าเห็นไฟล์เว็บที่ถูกต้อง แล้วคลิกขวาเฉพาะไฟล์ที่ต้องการส่ง เลือก **SFTP: Upload**

ยังไม่ได้เข้าสู่ระบบ FTP หรืออัปโหลดไฟล์จริง การตรวจที่ทำแล้วเป็นการเชื่อมต่อและเริ่ม TLS โดยไม่ใช้รหัสผ่าน
